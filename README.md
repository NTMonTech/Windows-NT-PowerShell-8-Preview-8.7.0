# Windows-NT-PowerShell-8-Preview-8.7.0 — экспериментальная сборка PowerShell 8 Preview для Windows, разрабатываемая в рамках проекта **Net Tweaking Studio**.

Проект предназначен для изучения, разработки и тестирования собственной сборки PowerShell 8 Preview с дополнительной инфраструктурой NT MonTech.

> ⚠️ **Preview / Experimental Software**
>
> Проект находится в стадии разработки. Он может содержать ошибки, незавершённые компоненты и несовместимости с отдельными версиями Windows или PowerShell.

---

## 📌 О проекте

Windows-NT-PowerShell-8-Preview-8.7.0 представляет собой экспериментальную среду PowerShell, основанную на экосистеме PowerShell 8 Preview и предназначенную для Windows.

Основные цели проекта:

* разработка собственной Windows-сборки PowerShell;
* эксперименты с PowerShell 8;
* исследование внутренней архитектуры PowerShell;
* создание компонентов NT для PowerShell;
* тестирование собственных модулей и инструментов;
* подготовка автономной среды PowerShell для Windows.

Проект распространяется с открытым исходным кодом.

📦 Установка

Если репозиторий содержит готовый установочный пакет, рекомендуется использовать его.

Установщик Windows MSI Installer:

PowerShell_8_8.7.0_Preview.msi

Запуск установщика:

msiexec /i .\PowerShell_8_8.7.0_Preview.msi

> Портативная версия, на случай если не хотите устанавливать от .msi установщика PowerShell_8_8.7.0_Preview.zip просто скачайте и распакуйте на рабочий стол

После установки проверить версию:

pwsh8.exe --version

или:

NT-Version (уже внутри самого PowerShell 8)
